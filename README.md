# Umamusume Racing Mod — Client

Official client distribution repository for **Uma Racing**, targeting Minecraft 1.21.1 with NeoForge.

Official project: https://github.com/NoteBlockMR/UmamusumeRacingMod

## Installation

1. Install Minecraft 1.21.1 and a compatible NeoForge 21.1.x release.
2. Install the required Umapyoi, Curios, and Mysterious Mountain Lib dependencies.
3. Place `uma-racing-client-0.3.0.jar` in the client `mods` folder.
4. Do not install the server-only JAR on the client.

The client package contains rendering, models, music, HUD, and server packet handling. It does not contain Uma Racing administrator command implementations or server configuration storage.
